Detailed Description

Function for finding the pointwise minimum of 2 arrays.

Note
D - shared3p protection domain
Supported types - uint8 / uint16 / uint32 / uint / int8 / int16 / int32 / int / float32 / float64 / fix32 / fix64 / xor_uint8 / xor_uint16 / xor_uint32 / xor_uint64
Parameters
x- first argument
y- second argument
Returns
an array with the pointwise minimum of each element in the two input vectors
Precondition
both input vectors are of equal length
Leakage
None
