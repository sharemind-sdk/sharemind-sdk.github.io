Compatibility notes

This version of the Sharemind Application Server is not compatible with older versions of the Sharemind Application Server and Sharemind Client API, including on the network protocols, configuration and API/ABI levels.

Added support for Debian 13 (Trixie), Ubuntu 24.04 (Noble Numbat) and Ubuntu 26.04 (Resolute Raccoon). Removed support for Debian 10 (Buster), Debian 11 (Bullseye), Ubuntu 20.04 (Focal Fossa) and Ubuntu 22.04 (Jammy Jellyfish).

Features

Emulator

  • Sharemind Emulator included in the Sharemind SDK VM is now based on the new Sharemind MPC Runtime library.

KeyDB

  • Added an option to the KeyDB module configuration to turn off access control so that all operations are allowed for all users and SecreC programs. By the default, access control is enabled and should be disabled only if other means for controlling access is in use.

SecreC compiler and standard library

  • Added N dimensional fixed point min and max to SecreC Standard Library.
  • Matrix multiplication now uses a parallelised version by default that multiplies N pairs of matrices in batch using Eigen and OpenMP.
  • Faster floating point matrix multiplication algorithm. The difference is increased by new shared3p floating point protocols in this release.
  • SecreC arrays no longer have an extra byte allocated. This breaks compatibility with previous versions of Sharemind VM and SecreC compiler.
  • Faster reading and writing of array slices. Added arrscatter and arrgather syscalls for accessing and assigining an n-dimensional slice of an n-dimensional array. The SecreC compiler generates code that takes advantage of these built-in syscalls.
  • Improved SecreC Standard Library test coverage.
  • Added Emacs mode for SecreC
